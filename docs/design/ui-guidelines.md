# 现场堪舆 UI 设计约定

版本：`field-ui-v1`，用于首版 OpenSpec 的实施设计，不表示页面已实现。依据 [UI 参考核查](../research/ui-references.md)，围绕现场测量、记录、复核、报告形成原创界面。

## 视觉方向

默认跟随系统明暗，也允许用户固定“瓷白”或“墨黑”。轻度铜金用于盘面选中刻度和重点边线；质量、保存与错误状态使用独立文字及语义色。首版不提供会打断读数的装饰轮播、闪烁光晕或自动跳页。

正文使用本地系统中文无衬线字体；角度数字采用等宽数字排布，避免实时变化时布局晃动。标题可以使用系统宋体作少量文化表达；角度、坐向、质量与按钮保持易读的无衬线。字体不从远程加载。

| CSS token | 瓷白 | 墨黑 | 用途 |
| --- | --- | --- | --- |
| `--fs-bg` | #F6F3EB | #111714 | 页面背景 |
| `--fs-surface` | #FFFFFF | #1B2420 | 卡片／表单背景 |
| `--fs-text` | #1F2926 | #F2F0E7 | 正文与角度 |
| `--fs-text-muted` | #52605B | #B6C2BA | 次要文字，仍须可读 |
| `--fs-accent` | #745A20 | #D3B16A | 选中山向、少量铜金强调 |
| `--fs-primary` | #225C47 | #D3B16A | 主操作背景 |
| `--fs-on-primary` | #FFFFFF | #152018 | 主操作文字 |
| `--fs-control-border` | #7A877F | #7F9488 | 输入轮廓与可见焦点 |
| `--fs-success` | #146747 | #90D5B0 | 稳定／写入成功文字 |
| `--fs-warning` | #8A4B0F | #E8C17B | 边界、待复核、未就绪文字 |
| `--fs-danger` | #AB302C | #FFAAA5 | 保存失败、无效输入文字 |

普通文字对比度至少 4.5:1，大文字和有意义的控件／图形至少 3:1。每次扩展颜色都检查实际前景与背景组合；不得以降低文字透明度破坏对比度。间距采用 4／8／12／16／24／32px，卡片圆角 12px，主要按钮高至少 48px、有效触控区域至少 44×44px，页面内边距默认 16px。

## 信息架构与页面

| 页面 | 默认可见内容 | 展开内容／下一步 |
| --- | --- | --- |
| 罗盘 | 当前项目／测点、对象、参考北、角度、坐山向山、地盘正针、质量与锁定／手录 | 样本统计、设备来源、原始精度、山界详情；保存后进入测点 |
| 项目列表 | 项目名、修改时间、测点数、保存状态、搜索与新建 | 归档列表、导入备份 |
| 项目详情 | 采用坐向及依据、测点列表、观察／图纸／报告入口 | 三次复测列表、人工修订历史 |
| 图纸 | 图纸、中心、方向标识、叠加模式、设置步骤 | 透明度、参考北转换、关联采用版本 |
| 资料 | 搜索、分类、已审核条目 | 来源／版本／原文／注释／说明；候选线索独立标记 |
| 报告 | 项目摘要、取向依据、原始测量、观察与人员判断 | 生成时间／版本、脱敏预览、HTML 导出与打印 |
| 设置 | 系统／瓷白／墨黑、离线状态、存储与备份、版本 | 安装说明、更新、清理确认 |

底部导航固定为“罗盘／项目／资料／设置”，图纸和报告从项目进入；≥960px 可采用侧栏与主盘／记录双栏。360px—959px 单列，页面整体无水平滚动；长列表、复测表与密集记录在手机上先展示摘要，再通过明确“查看详情”展开。不得把桌面密集表格直接缩成不可读小字。

## 罗盘首屏与详情

首屏按顺序呈现：项目／测点 → 对象与参考北 → 大字号角度及坐向 → 盘面 → 质量状态 → 主操作。角度使用约 48px 的响应式字号，坐向约 20px；正文至少 16px，次要状态文字至少 14px。低高度设备可缩小盘面，关键状态与操作不能被底部导航遮挡。

盘面只绘制启用的地盘正针与后天八方，不绘制看似可用的分金／天盘／人盘圈层。以角度模型确定读数，锁定后盘面、角度和质量快照同时冻结。文本区始终提供与图形一致的向／坐、宫位和数值；选中山界时同时显示相邻两山，不能只用红线暗示结论。

显示质量摘要：“采样中 2.1／3 秒”“可锁定 · 精度未知”“低精度 · 建议手录”“北向未知”“临近子／癸山界”。详细统计通过按钮展开；影响正式锁定的错误保留在主屏。图形解释和测量来源可折叠，权限拒绝／保存失败不可藏在详情内。

锁定后主操作为“保存测量”，次操作为“重新测量”；写入成功后显示该测点已保存记录数。保存失败时保留锁定值，提供“重试保存”和“导出草稿”，不得显示已保存。

## 组件边界

| 原创组件 | 输入／职责 | 可参考模式 |
| --- | --- | --- |
| CompassDial | 当前角度、盘层、山界、锁定状态；绘制方位 | Roxy 图形／图例分开，方向约定由本项目控制 |
| ReadingSummary | 向／坐、参考北、来源与质量摘要 | S17 关键值与元数据分层 |
| MeasurementActions | 按当前状态提供启动／锁定／保存／手录 | 明确动作，不将主题选择或登录加入测量前置流程 |
| SampleDetails | 采样时间、数量、离散度和精度来源 | 可展开详情，触控与键盘均可操作 |
| SurveyRecordCard | 单条测量、对象、时间、参考北及采用关联 | 紧凑摘要，原始数值可复核 |
| SourceDetails | 原文、说明、来源资格和固定版本 | 数据与解释分块，不从 UI 预览反推规则正确 |
| ThemePreference | 系统／瓷白／墨黑，保存本地偏好 | S16 的两主题选择，采用本项目 token |

首版不新增 MUI、Framer Motion 或 Roxy UI 为必需依赖，使用 React、CSS 与 SVG 完成这些组件。若后续选用第三方组件，独立确认许可证、中文标签、方向约定、局部打包、离线和打印；纯数据渲染与联网取数必须分开验证。

## 状态和访问性

- 主题切换只改变显示，保留正在采样的窗口、锁定值和未保存编辑；持久化失败仍可在当前会话使用主题并给出保存偏好失败提示。
- `prefers-reduced-motion` 时移除装饰过渡；正式读数与状态仍更新。实时盘面按最短角差旋转，359°→1°不绕远路；这是显示处理，不能改变领域计算或锁定数据。
- 屏幕阅读器按状态变化播报采样／锁定／保存／失败，避免把每条高频传感器事件重复播报。读数提供文本替代，状态不只靠颜色。
- 输入有永久标签、单位、范围和就地错误；详情支持点击、键盘与可见焦点，不依赖 hover。200% 文字缩放时状态与操作不被裁掉；图纸允许局部缩放。
- 离线、离线未就绪、数据未保存、仅内存、待更新是不同状态，各用具体中文文案；绝不把“缓存完成”显示成“项目已备份”。
- 所有核心按钮、空状态和错误使用简体中文。第三方英文 demo、静态演示数值和不具备的排盘功能不能出现在真实测量页面。
- 报告打印固定浅色、高对比、明确文字图例；主题设置不影响报告内容与脱敏选择。隐藏区域中的敏感内容必须在导出数据阶段省略。

## 对应规格与验收

`field-compass` 约束读数、冻结和质量；`survey-workspace` 约束移动布局、主题和渐进展开；`offline-pwa` 约束状态、安装和更新；`local-data-reports` 约束脱敏和打印。验收检查 360／390／768／1280px、200% 文字缩放、两种主题、减少动态效果、键盘、无 hover、离线冷启动及保存失败状态。

## 追加：现场参考校准与快捷户型

设备校准入口明确显示未校准原因、已知参考方位、参考北和来源，校准后常驻操作可锁定设备测量。项目中提供快捷户型模板与表单／触控编辑；门窗和障碍参数、评估依据用可展开详情减少长页面负担。评估结果显示形势倾向和待复核项，绘制线只作空间关系示意。
