# 验收矩阵

这是后续应用实现的验收依据，不是已经执行的应用测试报告。结构格式校验只能证明 OpenSpec 合法，不能证明手机精度、浏览器安装或实际 Pages 发布成功。

## 方向计算样例

输入默认测“向”，参考北为磁北；内部分类保留未舍入值。

| 向角 | 向山／坐山 | 八宫 | 提示或约束 |
| ---: | --- | --- | --- |
| 0° | 子／午 | 坎 | 北向零度 |
| 360°（手录） | 子／午 | 坎 | 归一化为 0° |
| 1° | 子／午 | 坎 | 与 359° 不能平均为 180° |
| 7.49° | 子／午 | 坎 | 显示 7.5° 但仍为子；提示子／癸界 |
| 7.5° | 癸／丁 | 坎 | 恰好山界，左闭右开 |
| 22.5° | 丑／未 | 艮 | 癸／丑界 |
| 90° | 卯／酉 | 震 | 正东 |
| 135° | 巽／乾 | 巽 | 东南 |
| 180° | 午／子 | 离 | 正南 |
| 225° | 坤／艮 | 坤 | 西南 |
| 270° | 酉／卯 | 兑 | 正西 |
| 315° | 乾／巽 | 乾 | 西北 |
| 337.5° | 壬／丙 | 坎 | 亥／壬界 |
| 352.49° | 壬／丙 | 坎 | 显示 352.5° 仍为壬 |
| 352.5° | 子／午 | 坎 | 壬／子界 |
| 359° | 子／午 | 坎 | 跨零子山 |
| -1°、361°、空值、NaN、Infinity | 不创建方向 | — | 手录报错 |

除上表，必须遍历全部 24 个山界 B 的 `B-0.01`、`B`、`B+0.01`，并核验所有中心角、宫位与相隔 180° 的对山；不以有限样例替代整表验证。

| 转换／聚合输入 | 预期 |
| --- | --- |
| 磁北 350°，D=+12° | 真北 2°，原始值 350° 保留 |
| 磁北 2°，D=-12° | 真北 350° |
| 真北 2°，D=+12°，目标磁北 | 磁北 350°，不能重复加偏角 |
| D 缺来源、适用日期或地点说明 | 不执行北向换算 |
| 359°、0°、1°（同对象同基准） | 推荐均值 0°，最短跨度 2°，用户确认生效 |
| 170°、180°、190° | 不自动确认，跨度 20° |
| 0°、180° | 合成向量接近零，不稳定，无可用均值 |
| 相同角度但磁北／真北未换算混合 | 不聚合 |

## 质量边界

| 条件 | 预期行为 |
| --- | --- |
| 3 秒 ≥10 样本，差值≤3°，合法姿态与已知北向 | 可成为稳定候选 |
| 9 样本／向量长度<0.1／角差>3° | 样本不足／不稳定，不能正式锁定 |
| beta 或 gamma 超过 ±15°、横屏 | 暂停正式锁定，手录可用 |
| 设备精度 ±10° | 标低精度，不能正式锁定 |
| 无精度字段、负数或非数精度 | 标精度未知，不伪造 ±值 |
| 2 秒以上没有新事件 | 数据过期，不能正式锁定 |
| 只产生相对 alpha | 北向未知，不能确认坐向 |
| 锁定后转动手机／切后台后返回 | 冻结快照／清空窗口后重测 |

## 实机与浏览器矩阵

每条记录包含设备型号、系统、浏览器版本、安装模式、测试日期、操作者、结果及证据。以下是计划目标，不代表已支持。

| 目标 | 手录与本地存储 | 传感器 | 安装／离线 | 报告 |
| --- | --- | --- | --- | --- |
| iPhone Safari + 主屏幕应用 | 必须通过 | 检查点击权限、WebKit 扩展、北向基准与姿态；未核实降级 | 安装引导与飞行模式冷启动 | HTML 导出／系统打印实测 |
| Android Chrome + 安装应用 | 必须通过 | 检查绝对事件、符号、姿态与北向基准；未核实降级 | 安装与飞行模式冷启动 | HTML 导出／打印实测 |
| 桌面 Chrome／Edge | 必须通过 | 无传感器显示手录 | 按能力安装，离线就绪后使用 | 键盘、打印、备份恢复 |
| 桌面 Safari／Firefox | 必须通过 | 允许手录降级 | 安装能力按平台说明；支持 SW 时验证离线 | 导出与打印 |

传感器对照在远离金属干扰的环境进行，测试北／东／南／西和跨零方向、竖屏／横屏、权限拒绝、低质量、前后台切换。记录相对实体罗盘的差值，不据少数测试宣布设备精度；参考北确认不了就不启用正式传感器测向。定位不是首版前置条件。

## 端到端验收

1. 完成联网资源准备 → 关闭应用 → 飞行模式冷启动 → 新建项目／测点 → 手录 179°、180°、181° → 确认向午坐子 → 添加事实和判断 → 导入图纸 → 设置中心与图顶朝东 → 查询子山 → 生成脱敏报告 → 下载完整备份。
2. 新浏览器导入备份，核对原始读数、图纸／照片、资料版本和历史报告；再导入一次，创建引用完整副本，不覆盖原项目。
3. 注入配额失败，当前草稿仍可导出、旧项目未变化；损坏／未来版本备份不产生部分写入；仅内存模式有明确提示。
4. 新版本在采样期间下载，应用不刷新；保存成功并确认后更新。坐向修改后旧报告不变、旧叠图待复核。
5. 两种部署 base 分别检查页面刷新、manifest 入口、图标、所有 chunk 和 SW scope；同源其他项目缓存和数据不被清理。
6. 默认报告不带详细地址、坐标和照片；导入脚本字符只作文本显示；本地文件和记录不出现在请求、URL 或日志。
7. 升级迁移故障和回滚旧代码时不清库，未知新 schema 提供只读／原始备份出口。
8. 360px 无整体横向溢出，主按钮≥44px、状态含文字；中文长备注、山界表和图片在离线打印中不被截断。只按平台真实能力说明保存 PDF。
