# 领域规则与测量约定

版本：`earth-plate-v1`。范围：地盘正针二十四山与后天八卦。来源：资料索引 S10；边界规则、质量阈值和数据字段属于本产品工程约定。

## 角度与坐向

- 方位角表示水平面方向：北 0°，东 90°，南 180°，西 270°，顺时针增加，内部归一化到 `[0, 360)`。
- `normalize(a) = ((a % 360) + 360) % 360`；只处理有限数值。手工录入接受 `[0, 360]`，360 显式转换为 0；负数、空值和超范围值提示错误。内部归一化不等于表单接受任意值。
- 用户选择当前测的是“向”或“坐”。若输入为向 H，坐为 `normalize(H + 180)`；若输入为坐，反向推向。不能把大门朝向自动认作全建筑坐向；记录建筑轴线、门向、窗口、来水、去水等对象类型。
- 每山中心间隔 15°，子中心 0°。顺时针数组为 `子、癸、丑、艮、寅、甲、卯、乙、辰、巽、巳、丙、午、丁、未、坤、申、庚、酉、辛、戌、乾、亥、壬`。
- 地盘山索引 `floor((normalize(H) + 7.5) / 15) % 24`。区间左闭右开：7.5° 属癸；352.5° 属子。计算使用未舍入值，界面显示一位小数并给出区间，防止显示舍入掩盖边界。
- 8 方位按二十四山三山归一宫；采用后天方位，不能套用先天八卦位置。
- 边界距离 `min(abs(wrapSigned(H - B)))`，B 遍历 `7.5 + 15k`；距离不超过 2° 时提示“临近山界，建议复测”，展示相邻两山。这不是流派“兼向／出卦”判定。

## 北向基准

`northReference` 为 `magnetic`（磁北）、`true`（真北）、`unknown`（未知），必须与读数来源分开保存。

- 首版默认传统盘使用磁北。真北测量／叠图须由用户主动选择并保留基准；没有有效换算参数时，两种北向不可混用。
- 磁偏角 D 以东偏为正、西偏为负：`Htrue = normalize(Hmagnetic + D)`；反向为 `Hmagnetic = normalize(Htrue - D)`。例如磁北读数 350°、D=+12°，真北为 2°。
- 首版手动输入 D（-180° 至 180°）、来源、适用日期和地点说明；标示“人工磁偏角”。可以引用 S09 的官方查询结果手录，不在应用内自动传送位置调用网络服务。
- 原始读数、原始基准和人工偏角保留，不覆写；重复查看报告不会重复加偏角。已知真北来源不能再按磁北处理。
- `absolute=true` 不足以保证该实现返回已确认的磁北。适配器声明须经实机对照，未验证实现保留 unknown。未知基准可存为待复核观察，不能确认正式坐向或用于平面图定向。

## 采样质量（工程初值，非仪器精度承诺）

- 平放手机，屏幕上沿指向观察对象；只在竖屏、倾斜 beta／gamma 各不超过 ±15° 的经过验证适配器上接受传感器正式锁定。横屏或不支持的姿态暂停锁定；允许手录，不做未经验证的倾斜补偿。
- 3 秒滑动窗口，至少 10 个有效样本；取环形均值，不能将 359° 与 1° 算成 180°。样本不足、2 秒无新事件、北向未知、姿态不满足时分别提示。
- 环形均值：对 sin／cos 分量求均值，`atan2(meanSin, meanCos)` 转角归一化。离散度采用各样本到环形均值的最短角差绝对值中的最大值；合成向量长度小于 0.1 时为不稳定，均值不用于锁定。
- 最大角差 ≤3° 且其他条件满足为稳定候选；大于 3° 提示复测。若有有效厂家精度字段且大于 5°，提示低精度并禁止正式传感器锁定；缺少字段写“设备精度未知”，不得伪造精度。负值／非数字段视为未知。
- 边界提示与稳定性分开：稳定候选若靠近山界仍须显示复测提示。阈值随质量配置版本保存，调整只影响新记录。
- 每个建筑坐向须有至少 3 条独立保存的测量（重新启动采样或手录）且同一对象、同一已知参考北。最短角跨度 ≤5° 时可推荐环形均值，用户明确确认后生效；跨度更大时保留全部读数并要求补测或说明后手动选值。手动选值始终标为人工确认。

## 术语与扩展边界

| 术语 | 首版处理 |
| --- | --- |
| 龙、砂、水、穴、向、明堂 | 资料卡解释和现场笔记分类；对象由人确认，不做自动地形识别 |
| 来水／去水、水口 | 记录方位、流向观察、照片引用与文字；不由单一方向计算水法吉凶 |
| 地盘正针 | 首版唯一计算盘层，清楚标识 |
| 天盘缝针／人盘中针 | 资料介绍；偏移规则与流派应用待审核，不提供可计算盘层 |
| 分金／兼向／替卦 | 后续独立规则集；首版只有数值偏离与山界提示，不给流派结论 |
| 三元九运／玄空／八宅 | 后续排盘需求须明确时间、历法、取向依据和版本，当前不输出盘 |

传统引文用于帮助理解分类。测量事实、传统解释、现场人员判断在数据与报告中各有字段，不合成一个“风水分数”。
