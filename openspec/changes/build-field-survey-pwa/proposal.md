# Proposal

## Why

专业现场堪舆需要把罗盘读数、观察对象、北向基准、环境记录和判断依据放在同一个可复核项目里，弱网场景也应能持续工作。建设可安装、可离线的静态 PWA，可直接托管在 GitHub Pages，降低部署和现场使用成本。

用户已明确第一版侧重“专业罗盘与现场堪舆”。资料与实施规格已建立，应用实现按本变更任务逐步推进。

## What Changes

- 新建前台罗盘工作流：手录实体罗盘及经过验证的手机传感器来源，显示角度、八方、二十四山、反向坐向和质量状态。
- 以地盘正针为唯一计算盘层，明确磁北／真北／未知、磁偏角、山界和采样噪声；不自动认定建筑取向。
- 增加项目、测点、多次测量、坐向确认、砂水及建筑环境笔记，保留人工修订轨迹。
- 支持本地导入平面图，手动指定中心与图顶方位，叠加二十四山和八方；不依赖地图或位置权限。
- 建立带来源、流派、版本、审核状态的离线资料库；测量事实、传统解释和人员判断分别呈现。
- 纳入用户提供的三个 GitHub 仓库核查结果，区分文件获取、许可和规则审核状态，并固定仓库提交；声明功能与实际代码冲突的内容只作为候选线索。
- 将 UI 参考转为原创现场界面：瓷白／墨黑主题、大字号读数、分组记录与可展开详情，保留中文、访问性和离线使用约束。
- 增加传感器现场参考校准，用户明确参考角度、参考北及来源后才能保存校准测量；未经校准不把相对姿态当北向。
- 支持模板快捷建立户型，编辑房间、门窗、入口和障碍物，绘制通达与直穿的示意线。
- 根据图示结构与用户记录评估室内藏风聚气、动线、通风和采光，每条结论给出依据与改进建议，缺项显示待补充。
- 支持本地持久化、完整项目备份恢复、脱敏报告和离线打印，避免只保留最终结果。
- 设计安装、离线准备、数据保存状态和无损更新流程，并适配 GitHub Pages 项目子路径及根路径。

首版不包含：自动三合消砂纳水、分金、玄空飞星、八宅、八字、AR 扫描、AI 咨询、在线地图、云账户／同步和交易功能。以上通过后续独立变更明确规则与数据前提后扩展。

## Capabilities

### New Capabilities

- `field-compass`：罗盘读数、北向基准、二十四山、坐向与测量质量。
- `survey-workspace`：项目、测点、现场观察、多次测量与正式坐向确认。
- `plan-overlay`：本地平面图导入、中心和方向设置、方位叠加。
- `knowledge-library`：可离线查阅、带来源与规则版本的资料库。
- `local-data-reports`：本地保存、备份恢复、脱敏报告和历史复现。
- `offline-pwa`：平台安装、离线准备、降级和更新体验。
- `github-pages-hosting`：纯静态运行、部署基路径、发布验证与回滚。
- `floor-plan-sketch`：快捷生成、编辑、保存和导出结构化户型示意。
- `indoor-qi-assessment`：室内形势、通达、通风采光检查及可追溯评估记录。

### Modified Capabilities

无。仓库尚无正式规格或已实现功能。

## Impact

当前已实现静态前端、方向计算、传感器能力检测、规则资料、IndexedDB、Service Worker、图纸、备份及报告快照，并建立验证与手动发布工作流。正式传感器适配及发布验收仍待实机记录。

实际仓库为 `https://github.com/unknownparticles/fengshui.git`，本地 remote 为 `origin`；计划部署地址为 `https://unknownparticles.github.io/fengshui/`，基路径 `/fengshui/`。2026-10-04 已推送并核实远端默认分支为 `main`，首次 GitHub CI 完整通过。当前手录版本已按用户明确授权发布到 `https://alunapp.cn/fengshui/`，HTTPS 已开启；手机实机与线上离线检查仍待完成。技术依据与内容边界见 [资料索引](../../../docs/research/sources.md)。
