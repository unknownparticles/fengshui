# Spec Delta

## Purpose

让没有现成图纸的现场用户从模板快速建立可编辑的户型示意，以房间、入口、门窗和障碍物记录空间关系，并在本机保存修订、参与方位叠加和报告输出，帮助后续室内观察复核。

## ADDED Requirements

### Requirement: 模板快捷建立户型
系统 SHALL 提供空白、一室一厅、两室一厅模板，建立带尺寸、房间、门窗及入口的本地户型。模板 MUST 标示示意且由用户确认实际布局，不能自动当作真实住宅。

#### Scenario: 两室一厅一键建立
- **WHEN** 用户选择两室一厅并填写总宽深
- **THEN** 系统生成可编辑房间与门窗，用户无需上传图纸即可继续记录

### Requirement: 编辑房间与开口
系统 SHALL 支持房间名称、用途、位置及宽深编辑，触控拖动与表单均可操作；门窗须绑定房间墙面，门可关联邻接房间或外部，入口必须为外门。无效尺寸、重叠房间、越界或非邻接内门 MUST 阻止保存并提示原因。

#### Scenario: 触控移动房间
- **WHEN** 用户拖动房间后调整宽深
- **THEN** 图示更新，保存前校验越界、重叠及门窗关联，表单可以完成等价编辑

### Requirement: 户型修订与方位
系统 MUST 保存户型修订、门窗和障碍物，图顶方位与参考北由用户明确提供；缺失方位时只展示空间关系。导出 PNG 可进入已有图纸叠加，完整备份与报告 MUST 保留结构及采用时的修订。

#### Scenario: 编辑后查看旧报告
- **WHEN** 用户生成报告后移动房间并保存新修订
- **THEN** 新项目采用新户型，旧报告仍显示原结构和修订
