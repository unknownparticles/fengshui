# Spec Delta

## Purpose

为现场人员提供可离线查阅的罗盘与堪舆资料，明确术语、方位规则、传统引文和现代说明的出处及审核状态，保持不同流派和内容版本的边界，使测量结果能找到对应解释。

## ADDED Requirements

### Requirement: 资料来源与审核状态

系统 MUST 为内容保存条目标识、标题、分类、来源名称、URL、章节／版本、作者或题署、获取日期、许可说明与审核状态。正式显示的内置内容 SHALL 为已审核；待复核条目只能在参考线索列表显示，不参与自动规则解释。

#### Scenario: 待复核流派资料
- **WHEN** 内容尚无确认版本或缺少完整来源
- **THEN** 系统将其列为待复核线索，不作为测量解释或盘层计算依据

### Requirement: 术语查找和离线基础资料

系统 SHALL 提供关键词搜索、分类筛选与离线全文查看，至少包含罗盘、坐向、二十四山、磁北／真北、后天八卦、龙砂水穴向、明堂及现场测量流程。二十四山条目 MUST 含中心角、区间、对山与后天宫位。

#### Scenario: 离线查询子山
- **WHEN** 用户离线搜索“子”并打开二十四山条目
- **THEN** 显示子中心 0°、跨零区间、对山午和坎宫；外部原始来源链接提示需要联网

### Requirement: 盘层与流派规则明确

系统 MUST 仅启用 `earth-plate-v1` 地盘正针计算，并在结果中显示规则集标识。天盘、人盘、分金、玄空与八宅 SHALL 作为未启用扩展的说明，不得将多个体系的表或偏移隐式混用。

#### Scenario: 用户查阅天盘资料
- **WHEN** 用户打开天盘介绍
- **THEN** 系统说明首版未启用该盘层，当前方向计算仍标为地盘正针

### Requirement: 原文解释与观察关联

系统 SHALL 将古籍原文、注释、原创现代说明和现场判断明确区分。观察记录可以关联资料条目，报告 MUST 保留当时引用的内容版本；传统理论不得表述为传感器验证的因果结论。

#### Scenario: 引用传统形势术语
- **WHEN** 用户将“明堂”资料关联到现场观察
- **THEN** 报告同时显示观察内容、人员判断和资料出处，不将引文自动转换为吉凶评分
