# Spec Delta

## Purpose

根据用户绘制的户型与实际观察提供室内藏风聚气和环境检查，把几何结构、传统解释、人员记录及待补充项明确呈现，帮助发现动线阻隔、入口直穿和通风采光需要复核的位置。

## ADDED Requirements

### Requirement: 可解释的室内检查
系统 SHALL 检查入口至房间的门路通达、同室外门窗直线贯穿、障碍物阻挡及外窗分布，并输出对象、依据、传统解释和建议。图示线 MUST 标为几何示意，不冒充真实气流、仪器测量或不可观测能量数值。

#### Scenario: 入口与对侧窗对齐
- **WHEN** 已确认户型入口与同一房间对侧外窗对齐且无绘制障碍
- **THEN** 系统提示存在直穿结构、说明传统穿堂的类比及现场复核需求，并标示对应示意线

### Requirement: 实际观察与缺项
系统 SHALL 允许逐房记录通风感受、采光、潮湿和备注，未记录值为未知。户型未确认、入口未设置或房间数据缺失 MUST 输出待补充项，不把未记录窗户或未知采光当成确定问题；不据图纸声称 CO₂、空气质量或风速实测结果。

#### Scenario: 未记录通风采光
- **WHEN** 用户仅生成模板，尚未确认布局或填写房间观察
- **THEN** 系统展示待确认／待观察清单，不生成肯定的藏风聚气结论

### Requirement: 评估快照与修订
系统 MUST 保存评估规则版本、户型修订、现场输入和输出快照；户型修改后旧评估标为待重新评估。备份、导入副本及报告 SHALL 保留相关引用和快照，后续修改不得改写历史结论。

#### Scenario: 户型修改后复查
- **WHEN** 用户保存新户型修订后查看旧评估
- **THEN** 系统提示依据旧户型，旧结论不变，允许按新修订重新评估
